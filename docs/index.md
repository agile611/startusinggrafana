# Curso de Grafana

Curso práctico de monitorización y visualización con Grafana sobre Ubuntu 24.04.5 LTS. Además este curso presenta un recorrido práctico por los fundamentos de la observabilidad y la monitorización utilizando Grafana, Prometheus y Node Exporter sobre Ubuntu.

## Recorrido del curso

1. Preparar el entorno de laboratorio.
2. Instalar Grafana, Prometheus y Node Exporter.
3. Configurar la recopilación de métricas.
4. Practicar consultas PromQL.
5. Crear un dashboard operativo.
6. Configurar alertas.
7. Preparar los entregables.
8. Consultar la documentación de referencia.
9. Resolver problemas habituales.

## Componentes principales

| Componente | Función |
|---|---|
| Node Exporter | Expone métricas del sistema |
| Prometheus | Recopila y almacena métricas |
| PromQL | Consulta las series temporales |
| Grafana | Visualiza métricas y alertas |
