# Grafana

Este bloque cubre la instalación, configuración inicial y primeros pasos con Grafana como plataforma de visualización y observabilidad.

## Objetivos

Al finalizar este bloque podrás:

- Preparar un sistema Ubuntu para instalar Grafana.
- Instalar y comprobar el funcionamiento de Grafana.
- Acceder a la interfaz web y realizar la configuración inicial.
- Comprender el uso de los selectores de tiempo y los intervalos relativos.
- Crear y organizar dashboards, filas y paneles.
- Conectar Grafana con una fuente de datos, como Prometheus.
- Construir visualizaciones básicas para analizar métricas.
- Diagnosticar problemas habituales de acceso y configuración.

## Contenidos

- Requisitos del sistema para Grafana.
- Instalación de Grafana en Ubuntu.

- Laboratorio práctico de instalación y configuración.
